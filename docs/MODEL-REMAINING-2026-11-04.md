## 仍未补齐

| 模型任务 | 实际缺口 | 可继续的路径 |
|---|---|---|
| ESD专用 | 新腕带模型召回不足，不判断未佩戴或电气合规 | 补齐公开项目剩余图片、提高近景检测召回，再补远景/遮挡样本 |
| 洁净服/帽/鞋套与洁净行为 | 无已核验可直接取得、适用且许可明确的完整权重/数据 | 合法取得完整公开导出；行为另需视频步骤标注 |
| 工业滴漏 | 候选Thalos实际不含leak；缺同域标注序列及有效权重 | 寻找或制作具有对应真值的滴落序列，不能以积水替代 |
| 密封钉 | 原作者检查点缺失；可见数据涉及3D及访问条件 | 可公开取得的同模态数据/权重；不拿普通焊缝代替 |
| 电芯六面完整缺陷 | 部分公开数据有许可/访问门槛，缺完整面别与缺陷覆盖 | 同域多缺陷数据与训练；六面SN汇总不是识别权重 |
| Pack装配/外观 | 未取得适用的通用Pack权重 | 明确装配对象与错漏装类别，再取得对应图像标注 |
| 弯针/压接深度 | 已有针脚分割与轮廓检查，不具备完整缺陷分类或3D能力 | 缺陷标签与适用成像条件；不把针脚掩膜判成OK/NG |
| 三防漆/胶体积 | 胶路两类模型不覆盖UV覆盖率与三维体积 | 对应光源/成像数据；不能改类别名称补位 |
| 工业SOP/远景睡岗 | VideoMAEv2是通用动作头，现有睡岗为规则 | 许可适合的工步/姿态时序数据与专用分类头 |
| PCB九类增强 | 数据已齐，但训练、额外测试分组和细微越界处理未完成 | 复用现有训练流程；本轮显存仅余0.6–1.4GB，未启动大数据训练 |

电机诊断与工业设备RUL仍缺跨工况有效权重；已有FD001只覆盖涡扇域。

烟火蒸汽/弧光、积水反光、小目标PPE、OCR、良品异常检测仍需各自的独立验证与质量提升，不以单图推理作为验收结论。
