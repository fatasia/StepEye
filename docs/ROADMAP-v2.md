## 0. 两条路线的关系(继承 v1)

| | 实时规则路线(已做:sop-vision) | 拍照即检路线(大模型,V 系列) |
|---|---|---|
| 触发 | 持续视频流 | 巡检拍照、定点相机定时上传、批量上传 |
| 样本需求 | 规则 + 现场标定,部分场景要训练 | 提示词 + 每场景 ≤3 OK / ≤3 NG 参考图,不训练 |
| 速度 | 毫秒到百毫秒 | 秒级到数十秒,异步排队 |
| 适合 | SOP、人车、持续监控 | 巡检、点检、首件检、低频场景 |
| 弱点 | 换型要调规则 | 大模型会判错、会编造、结果不稳定 |

结论:两条路线**共用同一套告警闭环、认证和看板**;"拍照即检"先跑起来积累误报样本,成熟后转实时检测器。v1"拍照即检提前"的决策已固化为阶段 0–2 主体。

## 1. 架构原则

### 1.1 三层蒸馏策略(场景定义不变,引擎自动升降级)

| 层 | 引擎 | 延迟 | 成本 | 适用 |
|---|---|---|---|---|
| 高频 | 蒸馏/训练的小检测器(D-FINE/RF-DETR 微调、AD 模型,OpenVINO/ONNX/工控盒 GGUF) | 毫秒级 | 边缘盒 | 节拍内全检、高频巡检点 |
| 中频 | Qwen3-VL-2B/4B 本地推理(llama.cpp/SGLang) | 秒级 | 单卡 | 拍照判定、UNCERTAIN 复核、班次级点检 |
| 低频 | 云端 API(glm-5.3-flash / GLM-4.5V 教师) | 秒到分钟 | 按次 | 首件对照、争议复核、蒸馏教师伪标注 |

**蒸馏触发条件 = 平台自动建议**(非人工决定):场景运行中误报率、UNCERTAIN 占比、样本积累量越过阈值时,平台提示"该场景可蒸馏为边缘检测器"。升级路径:教师伪标注 → 人工复核 → 蒸馏/微调 → **过回归集(闸门)** → 影子 → 发布/回滚。同一份场景声明之下换引擎,用户无感(见 [INNOVATION ①](INNOVATION.md))。

### 1.2 source 抽象,模态无关(点云留口)

视频源(source)是抽象接口,判定链/DSL/告警闭环对模态无感。点云**不进主线**:任何现有任务不依赖点云;但架构上留口——未来 RGB-D/点云作为新 source 类型接入即可复用全链。PoC 候选见 T25(W14 托盘码放 / W9 人车);锂电 Pack 涂胶不立视觉 PoC,走装备数据接入(T26)。

### 1.3 许可红线(ADR-03)

- Apache-2.0/MIT 可覆盖全部新选型;**Ultralytics AGPL 默认关**,仅客户已有授权时作开关;
- GPL(X-AnyLabeling)只作独立桌面工具,不 import 平台代码;
- ⚠ DEIMv2 license NOASSERTION:人工读 LICENSE 全文后再定;⚠ GLM-5.3 系许可已变,升级前复核模型卡;MVTec AD 2 学术用途限制,仅内部评测参考;
- 每次引入模型/数据集登记许可台账(T19)。

### 1.4 验证关卡纪律(已写入代码)

一致性×5 + 真值核对(拍照即检)/ 回放比对(实时)不通过不上线;禁用场景拒绝提交;判定锁低温 0.1;UNCERTAIN 转人工;向导末屏固定文案"验证的是一致性,不是准确率;正式指标需影子模式 ≥2 周"。

## 3. 光照治理四层方案(进相关任务验收标准)

依据:MVTec AD 2 已证明光照是域移最大杀手(RESEARCH-UPGRADE §10.5);参考分布对齐/TTA 线(arXiv 2503.14910、2408.09494)作算法层思路。

| 层 | 措施 | 落到哪些任务验收 |
|---|---|---|
| L1 物理 | 遮光罩/挡板,现场实施优先于一切算法补丁 | T13 现场实施验收;W 系列部署清单 |
| L2 相机 | 锁定曝光/白平衡,禁自动模式 | T12 相机接入配置项;T18 画质健康监控校验锁定未被改 |
| L3 算法 | 归一化互相关(当前帧 vs 参考图)判光照漂移;光照突变→降级 UNCERTAIN/停判;**多光照评测集**(白/夜/开灯/关灯子集) | T2(多光照评测集子集必须存在);T3(AD 引擎突变降级);T9(降级事件进告警) |
| L4 运维 | 班次参考图切换(白班/夜班参考图组,班次自动切换或提醒) | T7(参考图按班次管理);T16(样本池按班次归档) |

## 4. 点云与多模态策略(结论)

1. **不进主线**:T1–T20 无一依赖点云;
2. **架构留口**:source 抽象模态无关(§1.2),留口成本≈0;
3. **RGB-D PoC 候选**:W14 托盘码放(超高/超边/倒垛前兆)、W9 人车混行(车体体积+地面距离),挂 T25,触发条件=客户现场确有该需求且传统视觉被证明不足;
4. **锂电涂胶**:走装备数据接入(T26,涂胶机工艺参数),不立视觉 PoC;胶线视觉复核列为后续候选,不承诺。
