# ADR-001:拍照即检(阶段 3)提前

- 状态:**已接受(有条件)** · 日期:2026-11-02

## 背景

拍照即检不需要训练数据,对锂电「极耳翻折 / Pack 涂胶首件检」和安全巡检能快速做出可演示效果。
原排期把 V 系列放在阶段 3(登录认证与告警闭环之后)。用户决定提前,但**当前没有任何图片数据**;
大模型判定准确率(尤其指针表读数、首件缺陷)此前零实测。

## 决策

1. V1/V2/V3/V5 提到阶段 1 之后并行(新阶段 1.5),V7 告警闭环仍留在阶段 2——
   提前切片**先落库不推送**,补上告警闭环后自动接上,不返工。
2. 无数据起步按 [ROADMAP §5](../ROADMAP.md) 执行:代理视频帧 + 自拍 + 定向要客户样本。
3. 给客户的演示口径:讲链路与交互,**不讲准确率**;评测集建好前不承诺任何数字。

## 后果

- 好处:最快 1–2 周内有可演示的拍照即检切片,提前暴露大模型判定质量问题。
- 代价:V7 未就绪期间,告警只入库;演示数据与客户真实场景有差距,演示结论不可外推。
- 回退条件:V0/V5 冒烟显示 API 判定不稳定(JSON 解析率低、同一张图结论反复横跳),
  则 1.5 切片收缩为纯内部验证,不再对客户演示。
