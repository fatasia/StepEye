# ADR-002:大模型选型与 Provider 配置

- 状态:**已接受(V0 实测后修订)** · 日期:2026-11-02

## 背景

拍照即检需要一个多模态大模型。候选形态:本地部署(数据不出局域网,但本机 RTX 4060 仅 8GB,
只能跑 7B 级 4bit 量化)或云端 API(更准更稳,但图片出局域网)。
用户提供智谱 API:`glm-5.3-flash` + coding 端点,要求做成可配置。

## 决策

1. **Provider 抽象,API 优先**:推理入口统一走 `visual/llm_provider.VLMProvider`,
   端点 / 模型 / key 全部配置化(`.env` 或环境变量,优先级:环境变量 > .env > 默认值)。
   换模型只改配置,业务代码不动。
2. **默认配置**:智谱 `glm-5.3-flash`,`https://open.bigmodel.cn/api/coding/paas/v4`。
   公开资料显示该模型为原生多模态(320B/18B MoE,支持图片/视频/文件输入,官方归入 VLM 文档),
   来源:[Z.ai 博客](https://z.ai/blog/glm-5.3-flash)、[bigmodel 文档](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5.3-flash)。
   **coding 端点是否放行 image_url 以 V0 实测为准**(见 [V0-SMOKE](../V0-SMOKE.md));
   若不放行,降级方案是标准端点 `api/paas/v4` + 视觉模型(GLM-4.5V 级,改配置即可)。
3. **云端明示**:拍照即检默认走云端 API,图片将上传至智谱;界面上必须明示,
   不让「数据不出局域网」的可选项被静默稀释。客户要求物理隔离时再启用本地部署(备选:
   Qwen2.5-VL-7B / GLM-4.1V-9B 级 4bit,8GB 显存勉强可跑,许可与精度需届时逐一核实,当前不承诺)。
4. **凭据纪律**:key 只存 `.env`(gitignore 内),泄露即轮换;2026-11-02 该 key 曾在对话明文出现,
   **已提醒用户轮换**。

## 能力要求清单(给后续选型/换型的合同)

1. 视觉语言模型,**多图输入**(V5 首件对照一次最多 7 张:3 OK + 3 NG + 1 待检);
2. 中文指令跟随 + 可控 JSON 输出(解析失败按业务失败计,不猜);
3. 工位照片 1024px 级可用;表盘读数需高分辨率或裁剪策略(V4);
4. 价格与速率适合批量异步排队(V3 队列消化秒级延迟)。

## 后果

- 好处:零部署成本直接可用;模型迭代快,跟 API 比自部署 8GB 小模型准确率优势明显。
- 代价:数据出局域网(需客户知情);API 限速与计费随用量增长;断网即不可用(离线部署属阶段 6)。
