# 设置与运维

全局设置集中在「设置」，业务场景与工位参数留在「视觉应用」。

- 通用界面偏好保存在当前浏览器；不是所有用户共享的服务器配置。
- 用户管理复用现有 admin/operator/viewer 三角色：管理员管理用户，操作员执行业务写操作，只读用户查看数据。尚未实现按厂区/工位的细粒度权限。
- 最后一个管理员不能删除或降级；重设密码或角色立即撤销该用户旧会话和MCP令牌。账号管理要求启用服务认证。
- 操作日志记录写请求的用户、UTC时间、路由模板和状态码；不记录请求体、密码、token或URL查询参数。SQLite保留最近10000条，有界分页；日志写入失败不改变已完成业务结果，计数可见。它不是不可篡改合规审计，也不是系统日志收集器。
- 通知状态仅管理员可查；新渠道最近发送记录暂存内存，重启不恢复。实际配置与可选依赖见 [通知渠道](NOTIFICATIONS.md)。

服务/相机摘要用于诊断，不等同于CPU/GPU资源监控、磁盘告警或备份恢复。这些后续运维能力分别实现和验收，不以页面标题算完成。
