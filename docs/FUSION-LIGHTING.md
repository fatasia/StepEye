# 多源融合与光照门禁

给现场接入人员使用：设备信号只入队，采集线程统一求值；画面和信号不可用时不放行。

- 信号带来源、持久序号、采集时间、TTL 与质量；拒绝乱序、冲突、过期、超前时钟和超限请求。
- 状态融合先更新同帧全部观测，再求值；`all` 条件实时同时满足，不锁存已经过期的信号。
- 光照参考固定，持续异常不会自动“适应正常”；局部过曝、欠曝、背景不可用均进入门禁。
- 画质未知/异常立即阻断视觉取证；安全计时清空，恢复后重新观察。受影响周期进入 UNCERTAIN。
- 每项指标可在实时页「观测健康」和信号审计查询；上线另走[现场验收](INDUSTRIAL-ACCEPTANCE.md)。

## 1. 配置一个设备与视觉的共同条件

工位 YAML 中注册来源，并在相应步骤使用有保持时间的状态条件：

```yaml
signal_sources: [torque-controller]
steps:
  - id: tightening
    name: 锁付确认
    evidence:
      all:
        - obj_state: {zone: fixture, state: present, min_ms: 300}
        - signal: {source: torque-controller, name: tightening_ok, value: true, hold_ms: 100}
```

`hold_ms` 是来源状态须连续有效的最短时间，不是无限期缓存。TTL 由发送设备的刷新周期确定；发送端需要持续刷新状态，不能只发一次 true 后永不更新。`source` 缺省时同名来源不一致或任一已知来源失效，条件不成立；生产规则建议明确指定来源。

`seq` 仍表示分步先后证据；设备状态与视觉需要“同一时刻成立”时使用上面的 `all`，不要拿顺序证据替代同时性。

## 2. 发送与审计

调用 `POST /api/stations/{id}/signals`，沿用平台登录 Cookie 或 Bearer 会话，至少 operator 权限：

| 字段 | 要求 |
|---|---|
| source / name | 来源已在工位注册；设备与信号名称稳定不变 |
| sequence | 每工位×来源×信号的持久单调整数，设备重启不能从 0 重来 |
| observed_at | 采集端 Unix 秒时间，发送时计算；未来偏差最多 2 秒 |
| ttl_ms | 默认 5000，最大 600000；接收和消费时都检查 |
| quality / value | quality=ok/uncertain/invalid；值是有限 JSON，最多 16KB |

202 表示接收/入队，不表示设备动作已执行。同序号同内容返回 duplicate，不再执行；同序号不同内容/乱序为 409，过期 410，满队列/键数上限 429。每工位队列 128、持久信号键上限 256。`GET /api/stations/{id}/signals/audit` 查询 accepted/consumed/expired/abandoned 等收发状态，审计不保存测量原始值。

原 `/signal` 兼容 name/value，但来源固定为 `legacy-http`、TTL 2 秒，仅适合人工接入或迁移。它没有客户端幂等序号，无法去除网络重试；可靠设备改用 `/signals`。

重启/热重载不重放旧队列。当前部署只允许一个采集服务进程访问同一数据目录；不要用多个 Uvicorn worker 复制同一套工位。

## 3. 光照标定与故障行为

开启 `quality.enabled`，按现场数据设置亮度、模糊、全图/局部饱和比例和背景漂移阈值。默认每 5 帧采样、连续 3 次坏确认报警、5 次好确认恢复；原始坏/未知观测会提前阻断取证，不等待报警去抖。

参考首次在健康且背景可用时建立；之后只有明确重标定才更新。当前标定会同时更新 ROI 与质量参考，必须确认工作台/照明处于认可状态再操作。不能把某张异常图重新标成参考，代替独立真值验证。画质算法不修改检测输入，也没有把 CLAHE、亮度归一化当成通用精度补丁。

断流占位或超过帧间隔阈值的恢复首帧，清除旧视觉证据与安全计时；它不是一段“持续无人”的证据。RTSP/camera 恢复后重新去抖。两份仿真配置不测试真实相机位移，已显式关闭该项。

物理控制器判定扭矩是否合格；视觉确认位置、动作和物料。当前 HTTP 信号入口不是 PLC/OPC UA/Modbus 驱动，不提供设备动作事务、物理急停或密码学设备身份。具体设备驱动、单位/量程、SN/工件关联、时钟同步与断电恢复仍按目标设备联调。

## 4. 本机验证与未完成项

已覆盖合成图光照漂移/局部热点/欠曝、短闪与恢复、持续异常不自适应、空背景、质量恢复、安全重新计时、旧 VLM 结果失效；信号队列和融合覆盖 TTL、乱序、幂等、重启、同帧冲突、跨来源限定与非锁存条件。

这些是工程故障回归。目标厂区的昼夜片段、相机曝光锁定读回、真实 PLC/扫码/扭矩联调、长时间回放及至少两周影子记录尚未完成。不能据此给出现场准确率或安全完整性等级。
