# AI 服务与知识文档

管理员在设置中登记服务地址、模型和凭据，分别绑定问答与图片理解。已有环境变量配置继续作为未绑定时的后备；一次即检任务固定同一服务，设置变化从下一任务生效。

## 最短流程

1. 设置 → AI 服务 → 新增服务 → 测试 → 绑定用途。
2. 知识与文档 → 上传 TXT、Markdown、可提取文字的 PDF 或 DOCX。
3. 管理员发布版本；只读用户可检索已发布内容。
4. 打开全局助手提问，展开资料依据查看版本和原文段落。

未绑定问答服务时，助手直接返回文档检索结果，不调用模型。聊天只读，不修改工位或发布模型。对话历史仅保存在当前页面内存；文档原件、版本和索引存入服务数据目录的 `documents/`。

## 已接范围

- 服务凭据保存在服务端受限文件，接口只返回是否配置；测试状态区分文本与图片理解。通用图像生成绑定尚未接入，原样本生成器继续使用现有配置。
- 文档原件不可变，发布新版本归档旧版；文档发布不改变 SOP 检测规则。扫描 PDF 暂不自动 OCR。
- 文档检索复用 weihu 的分词与来源追踪思路，MIT 声明随模块保留；未引入常驻向量服务。
- 问答、文件解析与服务测试不进入实时视频循环。当前文档权限按角色区分，尚无按部门或设备的文档 ACL。

真实本机 Web 检查覆盖上传、发布、只读检索、助手引用与管理员设置权限；未调用云模型。检查记录位于 `.v0/output/playwright/documents-live/`。
