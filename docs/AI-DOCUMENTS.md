# AI 服务与知识文档

管理员在设置中登记服务地址、模型和凭据，分别绑定问答、图片理解与图片生成。已有环境变量配置继续作为未绑定时的后备；一次即检任务固定同一服务，设置变化从下一任务生效。

## 最短流程

1. 设置 → AI 服务 → 新增服务 → 测试 → 绑定用途。
2. 知识与文档 → 上传 TXT、Markdown、可提取文字的 PDF 或 DOCX。
3. 管理员发布版本；只读用户可检索已发布内容。
4. 打开全局助手提问，展开资料依据查看版本和原文段落。

未绑定问答服务时，助手直接返回文档检索结果，不调用模型。聊天只读，不修改工位或发布模型。对话历史仅保存在当前页面内存；文档原件、版本和索引存入服务数据目录的 `documents/`。

## 已接范围

- 服务凭据保存在服务端受限文件，接口只返回是否配置；测试状态区分文本与图片理解。已接通用图片生成绑定，原增强/CogView/lk888入口保留。
- 文档原件不可变，发布新版本归档旧版；文档发布不改变 SOP 检测规则。扫描 PDF 暂不自动 OCR。
- 文档检索复用 weihu 的分词与来源追踪思路，MIT 声明随模块保留；未引入常驻向量服务。
- 问答、文件解析与服务测试不进入实时视频循环。当前文档权限按角色区分，尚无按部门或设备的文档 ACL。

真实本机 Web 检查覆盖上传、发布、只读检索、助手引用与管理员设置权限；未调用云模型。检查记录位于 `.v0/output/playwright/documents-live/`。

## 图片生成

设置中保存支持 OpenAI 兼容 `/images/generations` 的服务并绑定“图片生成”；样本库选择“已配置服务”，填写描述后生成。当前支持 `b64_json` 返回，不支持仅URL返回或图生图；参考图留在本机，不发送到该服务。

每张最长30秒、单批最多8张，同一时刻一个生成请求，工作在线程池，不阻塞实时视频事件循环。输出须为单帧PNG/JPEG/WebP，最多400万像素，解码后重新编码为JPEG。失败项不计入成功图片。

参考图按SHA256保存原字节，生成记录带稳定来源组、实际模型名和用户意图标签；生成标签需人工复核，合成样本不进入验收集。能力验证使用本机HTTP协议服务，无云端生成效果或费用结论；截图 `.v0/output/playwright/configured-image/configured_image_1920.png`。
