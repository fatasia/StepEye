# 标注评测自动监测

在「固定模型评测」打开一份报告，展开「后续评测监测」，点击「以此报告为基准」。此后同一项目、模型、适配器和预测协议的新评测入库时自动比较，不需要再手动选基准。

- 复用现有报告库和P/R比较，无新推理、轮询或常驻线程。
- 默认两批各至少20图，逐类分母各至少20；下降10个百分点标记「精度观测下降」。样本不足单列。
- 结果与新报告同一事务保存，历史结果不可覆盖；重启不补跑旧报告。换基准只影响后续报告。
- 页面展示监测状态；下降报告在历史列表标记，完整比较随报告JSON导出。可一键停止。

这项监测由**新的人工作业已复核评测报告**触发，不自动生成现场真值。数据分布、标注和采集变化尚未分离，提示不直接触发模型回滚或安全告警。

## 接口

`GET /api/evaluations/holdout/{report_id}/watch` 查询配置和该报告对应观察结果。

`POST /api/evaluations/holdout/{report_id}/watch`：

```json
{"enabled":true,"min_samples":20,"min_drop":0.1}
```

`enabled:false`停止对应项目/模型/工作点的监测。沿用现有评测权限，viewer不能修改，未适配全局评测入口的受限用户仍返回403。

范围同时绑定project_id、engine_id、模型SHA、类别顺序、适配器、置信度/IoU及预测协议，不拿其他工位项目或不同阈值的结果作同一基准。每个范围只有一个当前基准；自动观察保留当时的baseline_id和阈值。

## 已验证

真实微型ONNX与冻结图像通过现有Web完成：首报告→设为基准→第二次评测自动附带样本不足结果→报告对比/下载；1920截图 `.v0/output/playwright/accuracy-watch/report_1920.png`，页面错误0。单元覆盖下降、分母不足、范围隔离、关闭/换基准、事务回滚、重启和权限。夹具验证工程行为，不是厂区精度结论。
