# 平台缺口地图 + 翻包/仓储物流场景清单

> 2026-11-02。回答两个问题:①现有 SOP/安全/质量三域离"完善 AI 视觉平台"还差什么;②翻包仓库、仓储物流场景能做什么。
> 编号沿用 ROADMAP(V=拍照即检, S=实时安全, Q=质量, B=平台底座, R=工程化);新场景任务用 **W 系列**(仓储 Warehouse)。

## 一、平台缺口(按层,标了对应排期)

| 层 | 缺口 | 对应任务 | 状态 |
|---|---|---|---|
| 账号与安全 | 登录认证、RBAC、操作审计;API key/凭据管理 | 阶段 2 | 未开始(V7 前置) |
| 告警闭环 | 告警中心(待处理→处理中→已处理/误报)、飞书推送、误报复核回流 | V7、B3 | 未开始 |
| **常驻安全规则** | 现有引擎是**周期驱动**的 SOP 状态机;S16 无人值守/S17 聚集/S1 入侵这类**与周期无关的持续监控规则**没有执行器 | 阶段 4 | ◐ 本轮落地了人员感知 + 条件求值,**常驻规则执行器是下一步** |
| 检测器接入层 | 通用 detector 适配(人员/PPE/车辆)、模型包管理与签名 | B0、R11 | ◐ 人员感知本轮落地;PPE/车辆检测器未接 |
| 评测与回归 | 固定样本集、一键跑分、提示词版本化、换模型对比 | B2、V6 | ◐ 工具雏形已有(tools/eval_*),回归基建未做 |
| 多相机规模化 | 站点管理、相机标定向导、断流/画质健康监控 | V9、阶段 6 | 标定向导/区域编辑未做(界面已留占位) |
| 数据闭环 | 反馈样本池、误报→再训练→影子发布 | R6、R7 | 未开始 |
| 视频留证 | 录像切片(ZLMediaKit)、证据签名、保存/清理策略 | R3、阶段 6 | 证据哈希有,签名/策略未做 |
| 设备/MES 集成 | 扭矩枪/扫码/PLC 信号接入(视觉测不了扭矩——方案红线)、SN 绑定 | 阶段 5 | 未开始 |
| 工程化部署 | 离线包、容器化、升级回滚、平台自身可观测性 | R11、阶段 6 | 未开始 |
| 看板报表 | 检测趋势、异常率、按场景分布 | V8 | `/api/inspection/stats` 有数据源,无 UI |
| 许可合规 | 每个模型/数据集的许可台账(ADR-03 红线) | 持续 | README 有声明,无台账 |

**结论**:三域能"跑起来给人看",但作为可签合同的平台,缺的不是算法,是**账号、告警闭环、常驻规则、评测回归、工程化**这五件平台底座——全部已在排期里,属于阶段 2/4/6 的主体。

## 二、翻包仓库场景(拆箱→核对→重包装工位)

| # | 场景 | 路线 | 说明 |
|---|---|---|---|
| W1 | 拆包 SOP:拆封条→开箱→清点→重封的顺序/漏步 | 实时规则 | 现有 SOP 引擎直接可配,zones=封条位/箱体/清单区 |
| W2 | 封条完好 + 封箱胶带起翘/折叠不良 | 拍照即检→实时 | 巡检拍照起步;胶带质量需特写相机 |
| W3 | 装箱清单核对:件数/错漏装 | 实时+信号 | 件数视觉+电子秤/扫码信号互补 |
| W4 | 面单/条码/警示标粘贴(位置/有无/朝向) | 拍照即检 | OCR 类先走大模型,量大后转专用 OCR |
| W5 | 箱体破损/变形/污染/受潮 | 拍照即检 | 巡检+翻包台定点拍照 |
| W6 | 拆包刀具/剪刀使用合规(划伤风险、工具归位) | 实时规则+大模型 | 刀具在位检测(实时)+使用姿势(大模型复核) |
| W7 | 翻包台 5S(台面杂物/工具未归位) | 拍照即检 | 低频巡检,换班拍照 |
| W8 | 堆垛码放规范(高度/超边/混层) | 拍照即检→实时 | 定点拍照起步 |

## 三、仓储物流场景(库房/月台/充电区)

| # | 场景 | 路线 | 说明 |
|---|---|---|---|
| W9 | 人车混行/叉车接近人员 | 实时规则 | 检测器接入(PeopleNet 类→许可干净替代)后经典场景,S1 同族 |
| W10 | 通道/消防区占用、货架阻挡 | 实时规则+拍照即检 | 区域入侵规则;巡检拍照兜底 |
| W11 | **锂电仓储充电区烟火/热失控前兆** | 实时+大模型 | GB 38031-2025 驱动;烟雾实时+红外融合是后手 |
| W12 | 月台边缘跌落风险(车门未到/人靠近边缘) | 实时规则 | 区域+人员条件,复用本轮 person 感知 |
| W13 | 库位/托盘条码 OCR 核对、错拣校验 | 拍照即检 | 拣货拍照核对,OCR/大模型 |
| W14 | 托盘码放(超高/超边/倒垛前兆) | 拍照即检 | 定点定时拍照 |
| W15 | 地面异物/积水/撒漏 | 拍照即检 | 巡检拍照,误报可容忍(UNCERTAIN 转人工) |
| W16 | 车牌/月台到货识别 | 拍照即检 | 月台定点相机拍照 OCR |
| W17 | 充电区作业规程(充电枪归位、无人值守充电) | 实时规则 | 复用无人值守条件 |

**优先级建议**:W1(现引擎直接可配,最快见效)→ W5/W7(拍照即检零训练)→ W9/W12(需人员/车辆检测器)→ W11(差异化卖点,锂电客户强需求)。

## 四、本轮已落地(2026-11-02)

- **三个安全条件进 DSL/引擎**:`person_present` / `person_absent`(S16 无人值守)/ `person_count`(S17 聚集),可做步骤证据
- 缺口地图与本场景清单(本文件)
