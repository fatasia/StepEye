## 接入方式

1. 保留来源 DOI、原始类别和文件哈希，单独创建九类项目；不把旧六类模型的类别头直接改名。
2. 通过现有样本导入／训练队列增强，先核对类别含义及来源分组，再生成 YOLO 标注格式。不新建训练服务。
3. 原包仅train/val，不能将调参用val冒充独立测试；后续固定额外留出组，并核查近重复与同板裁剪来源。
4. 本轮未训练、未新增模型权重、未自动发布。数据许可与未来训练框架／模型许可分别记录。

原始元数据、下载断点、完整标注和审计记录保存在 `.v0/dspcbsd/`。完整包状态与实测去重结果见下方本轮记录。
