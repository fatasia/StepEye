# 上传存储配额

管理员可限制样本、文档和设备结果目录的新数据写入。默认不限制，不删除旧数据，不拦截实时检测或告警证据。

启动服务前设置进程环境变量，重启生效：

```powershell
$env:STEPEYE_STORAGE_LIMITS_JSON='{"labeling":10737418240,"documents":1073741824,"equipment-results":21474836480}'
```

```bash
export STEPEYE_STORAGE_LIMITS_JSON='{"labeling":10737418240,"documents":1073741824,"equipment-results":21474836480}'
```

值为字节；省略目录表示不限，0表示禁止新增。仅接受这三个目录名和非负整数，配置错误时启动失败。现有管理员接口 `GET /api/operations/storage` 返回相同配置及实际目录用量；没有新增设置页面或后台线程。

## 已执行的入口

- 样本图片、YOLO ZIP导入、调用同一存储层的生成样本：同时计算原件和解码后的PNG。单批按图片逐项导入，已成功项保留，超限项进入原有错误列表。
- 数据集版本导出：包含图像、标签、清单与ZIP，提交前校验最终临时目录用量；失败删除本次临时目录，已有版本仍可下载或幂等获取。
- SOP/知识文档上传：超限返回413；解析或数据库失败清理本次原件。
- AOI/AXI等设备图片导入：先检查原件，再检查所有规范化PNG；超限回滚整批记录并清理暂存文件。已存在幂等键的相同结果仍可读取。

同一服务实例按目录串行完成检查和落盘，避免并发上传使用同一份剩余容量。未配置的目录不扫描、不加锁。既有API错误格式不变，直接上传超限为413；批量样本仍通过原有逐项错误显示失败。

## 范围

这是上传准入限制，不是文件系统硬配额。统计包含目录中的SQLite/WAL，但提交后的索引增长不回滚；下一次新增按最新用量判断。暂存规范化图片或ZIP可能短暂超过配额，拒绝后清理。外部脚本、多个服务进程共同写一个数据目录、实时证据、训练输出、Monibuca录像不在该门禁中；这些目录需要操作系统磁盘配额或独立保留策略。不会为腾空间删除历史证据。
