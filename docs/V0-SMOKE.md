## 结论(ADR-002 修订依据)

1. **coding 端点可用作拍照即检的推理通道**,不需要切换到标准端点。
2. 模型对真实工位画面的理解质量足以支撑 V2/V5 的提示词判定路线。
3. 单样本一致性 100% 是好信号,但**这只是稳定性,不是准确率**——没有人工真值,
   不能外推到「判定正确率 ≥x%」。准确率结论必须等评测集(ROADMAP §5)。

## 边界与已知局限

- 单张图、单条提示词、一次会话,样本量 1;换场景(反光、蒸汽、密集小目标)未验证。
- 「手套 NG」判定是模型自洽输出,未经真值核对(视频里工人确实裸手,目测一致,但目测不是标注)。
- 未测多图输入(V5 首件对照一次最多 7 张)——**这是下一步必测项**,多图可能显著改变显存/精度/延迟表现。
- 未测延迟分布(T3 单次目测秒级,未精确计量);V3 队列设计时需实测 P50/P95。

## 下一步(V0 续)

1. 从两段视频抽 10–20 帧多样化样本(手部姿态、遮挡、桌面物 variety),跑手套判定并人工核对,
   形成第一份**带真值的迷你评测集**(哪怕 20 张)。
2. 多图输入冒烟:3 OK + 3 NG + 1 待检的模拟首件对照,验证 V5 两步判定提示词。
3. 延迟计量:单图 P50/P95,确定 V3 队列的并发与超时参数。
