# 标注工作台

在 StepEye 的样本库里整理框级训练数据：模型先提建议，人确认后导出。

- 不需要模型也能手工框选、移动、缩放、改类别和撤销。
- 先试两张，逐张确认效果后再批量；未检出不自动变成背景。
- 草稿有修订号，冲突返回409；已确认结果不被自动任务覆盖。
- 批量任务存 SQLite，关页面继续运行，进程重启可恢复；单图推理隔离为可终止的 CPU 子进程。
- 确认版固定图片、修订、分组和哈希，导出 YOLO ZIP；相同原件/正向图片/来源组不跨训练与验证集。

## 最短路径

1. 打开「样本库 → 标注工作台」，新建项目。使用现有检测器时，沿用该模型的完整类别名称；新类别可先手工标注。
2. 导入照片。同一视频/连续拍摄批次填写相同来源组；生成图勾选合成，填写来源与许可引用、光照分桶。
3. 点击「先试两张」。修正漏框、误框和类别；没有目标时，明确勾选空背景再确认。
4. 选中其余图片，批量预标注，优先检查问题图。保存草稿不等于人工确认。
5. 打开「确认版与导出」，生成版本并下载 ZIP。只有当前已确认的框或背景进入该版本。

历史恢复会产生新的人工草稿，不删除过去的确认记录。若恢复后尚未重新确认，新版本不会收录该图；已生成的旧版本仍可导出。

## 预标注引擎

首批复用当前 YOLO v5/v8 风格 ONNX 原始输出适配器，不替换 YOLO 或权重。支持单输入 float32 NCHW 640、单输出模型；D-FINE/RF-DETR、端到端 NMS、多输入/输出模型需要专用适配。

CPU 推理需要 `onnxruntime`。引擎来自本机工位配置或已有安全帽评估权重；网页不接受模型文件路径、下载 URL 或命令。未安装模型、类别不匹配、单图失败时仍可手工完成。

无排队任务时不常驻标注线程，队列清空即退出；下一次提交或启动时有未完成任务才唤醒。单个推理进程默认30秒超时，最多4个排队/运行任务，每批最多200张。取消保留已落库建议，不继续处理剩余图片。任务中的图片若被人工修改或确认，该项跳过。

## 导出不是训练验收

ZIP 包含 `manifest.json`、`metadata.json`、类别表、相对路径 `dataset.yaml` 和图像/标签。同组与精确重复自动合并分组，合成组只进入训练集；近重复识别与视频代表帧抽样后续补充。

许可引用不是许可审核记录。导出元数据中的 `licenses` 默认留空，训练前按 [训练准备](TRAINING-READINESS.md) 补齐；样本量、验证组和许可不合格时，`training_preflight.py` 仍会阻止训练准入。标注完成不改变模型或原图的许可。

多光照独立回放、框级评测和现场影子仍按 [工业验收](INDUSTRIAL-ACCEPTANCE.md) 执行。视频/影子证据一键导入、分割辅助和开放词汇引擎不在首批范围。

MCP 的本机接入和外部连接器见 [MCP](MCP.md)。


## 导入已有 YOLO 标注

在标注工作台选择项目 → 导入标注 ZIP。包内提供 `classes.txt` 或 `data.yaml`/`dataset.yaml` 的 names，以及 images/labels 对应目录（可含 train/val）。先按类别名称映射，不要求编号一致。单包最多200张图、压缩和解压均不超过100MB。

导入结果逐张列出成功和错误；有效框进入待复核草稿，缺标签保持未标注，空标签不自动确认背景。整包默认作为同一来源组，重新划分时避免同视频泄漏；合成数据勾选后只进入训练集。未知类别或非法框先修正，再重导对应数据。当前仅检测框，不导入分割多边形。
