# 浏览器数据范围

管理员可为用户选择可访问的样本项目。项目的 `scene_id` 同时决定可见工位和告警，不新增另一套工位授权表。

- `project_ids: null`：全局；旧用户迁移后保持此状态。
- `project_ids: []`：无项目，不能清空后变成全局。
- `project_ids: ["LP-..."]`：指定项目及其关联工位。管理员只使用全局范围。
- 修改范围、重设密码或修改角色会撤销旧会话；已连接的 WebSocket 在下次发送前关闭，空闲连接最多5秒复查一次。

## 管理接口

`GET /api/users`、`GET /api/auth/me` 返回 `project_ids`。浏览器会话另有 `scope_type: all | projects`，与旧 MCP 空数组表示全局的约定区分。

`PATCH /api/users/{username}/scope` 接收必填的 `project_ids`，仅管理员可用。不需要重设密码。

`POST /api/users` 可显式传范围；编辑用户时省略此字段会保留已有范围。新用户省略时保持兼容的全局范围。

## 当前覆盖

受限用户可在授权项目内查看/上传/导入数据集、编辑与确认标注、导出版本、预标注和训练任务；角色读写限制仍然生效。

工位列表、状态、画面、预览、配置操作按项目关联工位检查；告警列表在分页前筛选，统计、误报分析和状态修改使用同一范围。WebSocket 首包和后续事件均过滤工位。

模型目录、引擎列表、训练能力与单图试跑是共享运行资源；不能据此创建新项目或读取其他项目图片。

尚未接范围的全局业务接口对受限用户返回403，包括全局文档/助手、机理报告、即检记录、时间轴和样本生成历史。内部证据导入也暂不开放，避免通过授权的目标项目读取未授权来源图片。全局用户行为不变。
