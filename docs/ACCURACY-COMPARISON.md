# 标注回流精度对比

在固定评测报告详情中选择基准报告，比较同一模型在两批已复核样本上的 Precision / Recall。复用不可变 HE 报告，不重新推理、不增加线程，也不自动回滚。

## 使用

1. 对新确认版样本运行一次既有固定评测。
2. 打开报告中的「与基准对比」，选择同模型历史报告并比较。
3. 查看逐类变化；需要留档时导出对比 JSON。

基准列表显示最近 100 份报告中的同 SHA、同适配器候选；服务端再检查类别顺序和置信度/IoU 工作点。没有相同模型的历史报告时先建立基准，不拿新旧模型的差异冒充同一模型退化。

## 判定口径

- 两份报告都须来自检测验证，并保存逐帧已复核真值和逐类 TP/FP/FN。
- P/R 从 TP/FP/FN 重算，不使用预测置信度均值，不用未复核告警推断准确率。
- 默认两批各至少 20 张图；每类 Recall 的真值数量、Precision 的预测数量也各至少 20。分母不足或不存在时显示「样本不足」，不触发该指标下降提示。
- 默认下降 0.10（10 个百分点）提示「观测下降」。按类检查，整体平均不掩盖稀有类别下降；阈值是可配置的观察规则，不是统计显著性检验。
- 不同数据版本会明确标记；数据难度、采集条件、标注变化和模型退化无法仅靠这两份报告做因果区分。预测导出协议变化另行提示。

## API

`POST /api/evaluations/holdout/compare`

```json
{
  "baseline_id": "HE-baseline",
  "current_id": "HE-current",
  "min_samples": 20,
  "min_drop": 0.1
}
```

返回双方报告/模型/数据 SHA、工作点、逐类计数与 P/R 变化、样本量、`status` 和 `automatic_rollback:false`。不修改源报告或发布账本。

沿用既有 POST 权限：全局 operator/admin 可调用，viewer 和限定项目范围用户不可调用。后者与当前固定评测全局入口一致，尚未开放跨项目报告访问。

组件 `mountHoldoutCompare(host, currentReport, {canWrite})` 嵌入现有详情；数据按展开时读取，比较由用户明确触发。

12 项定点检查覆盖变化/不足/同数据、同模型与工作点约束、无真值拒绝、阈值、权限与报告不可变；组件通过 JS 语法检查。实际页面交互由主线集成验收。
