# 从应用开始

「我的应用」是日常入口。模型、样本项目和部署工位由应用绑定，不必复制场景 ID。

## 创建第一个应用

1. 点「新建应用」，选择安全监测、SOP 防错或外观异常。
2. 接入 RTSP、ONVIF、国标平台、USB 相机或上传视频，点「测试连接」。国标平台先在「设置 → 运行状态」配置 WVP；没有相机可选择演示画面。
3. 先试运行，核对正常与异常操作，再点「确认效果并启用」。试运行保留证据，不推送告警。

SOP 应用进入「编辑步骤」设置名称、顺序、完成条件和超时；到「检查区域与规则」画区域、采集参考图。周期进行中不能切换规则，等待当前工件结束再保存。

外观应用先登记良品，再检查其他图片。可在高级选择中决定是否使用 DINOv2；算法与阈值、辅助校准、参考库版本均留在良品检测里。正常结果只进入检测历史，异常按策略进入告警。绑定相机后每5秒取最新健康画面检查，繁忙时跳过，不堆积帧。

## 光照处理

安全与 SOP 应用可在创建时或暂停后的「画面优化」中启用自动曝光校正；校正只用于检测输入，原始画面、留证和画质判断保留原图。外观应用在「管理良品与检测 → 算法与阈值」中选择光照处理，良品和待检图使用同一设置；切换设置会重建参考库并保留旧版本，需要重新核对阈值。可用待检图预览校正效果。

校正是有上下限的亮度增益，不能恢复已经丢失的细节；使用不同光照、正常与异常样本核对后再启用。

## 增强与维护

- 安全应用的「样本增强与版本」带入当前项目、模型和工位，继续标注、训练、评测、审批和回滚。
- 「设置 → 运行状态」可安装、取消或启用独立训练环境。安装需要 Python 3.10–3.13、网络和数 GB 磁盘空间。
- 国标应用在每次启动时重新请求 WVP 点播地址；ONVIF 可搜索局域网相机或手动输入地址和账号。
- 「设置 → AI 服务」绑定模型服务；「拍照即检 → 新建检查规则」填写检查要求。
- 「设置 → 通知状态」粘贴机器人地址、保存渠道并发送测试消息。送达结果以通知状态为准。
- 本机首次运行可在「设置 → 通用外观」创建管理员并启用登录；此选择在重启后保留。

应用状态及输入配置保存在当前数据目录，重新启动后恢复已启用和试运行的应用。
