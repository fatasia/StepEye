2026-11-03。以实际代码与检查记录为准；任务名称来自用户补充，表内旧技术选型与工作量不作为强制要求。公开数据由开发侧检索获取，不以等待客户数据作为通用开发的前置条件。

“基线可用”指列明范围的软件实现可运行，不代表全部行业场景或现场精度已经验收。测试替身、自制几何样本、公开视频推理、独立标注集指标分开记录。

## 当前执行顺序（2026-11-03 用户调整）

1. **最高优先：实时安全与仓储、工业专用质量、特殊设备信号。** 三路并行，先接现有权重和接口，缺少的再找公开模型或训练。
2. 其余按此前顺序：AI 服务与助手 → 文档与 SOP → 机理实验室 → 模型发布流程 → 推理效率 → 接入与运维。当前小块收尾后顺延，不删除任务。
3. 复用检测、信号、告警和模型登记；不新建同类系统。只跑改动相关检查和必要整合检查，不重复多分辨率矩阵。输入单位、时间和权限检查保留，其余不扩无关框架。
