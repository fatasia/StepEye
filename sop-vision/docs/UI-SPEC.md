# 视觉实验室 · SOP 合规平台 — 界面规范 v1

> 定位：工位级工业监控台。对标 **西门子**（信息密度高但不乱、状态三重编码、术语唯一）、**帆软 FVS**（图表规范、数值格式）、**山海鲸**（克制的空气感）。  
> 约束：纯静态前端（无构建、无外部 CDN），可在断网工厂内网直接运行。

---

## 1. 设计令牌（唯一来源：`web/css/tokens.css`）

所有颜色、间距、圆角、动效曲线只能引用令牌；**强调色由 `--accent-primary` 派生**，用户换主题色后全站同步。

| 类别 | 令牌 | 深色（默认） | 浅色 |
|---|---|---|---|
| 背景 | `--bg-0` | `#0b1114` | `#eef2f4` |
| 表面 | `--surface-1/2/3` | `#11191d / #172126 / #1c282e` | `#ffffff / #f6f8f9 / #edf1f3` |
| 线 | `--line-subtle / --line / --line-strong` | 浅灰 α .10/.14/.26 | 深灰 α .08/.14/.28 |
| 文字 | `--text-strong / --text / --text-muted / --text-faint` | `#e6ecef / #a7b2b8 / #8b989f / #738189` | `#10191d / #3b484f / #5b6a72 / #7b8991` |
| 主色 | `--accent-primary` | `#3ec6c1`（可被用户覆盖） | 同左 |
| 语义 | `--success / --warning / --danger / --info` | `#59c58d / #d8ac52 / #e27478 / #65aee8` | 同左（浅色下加深） |

- 字号基准 **13px**；数字一律 `tabular-nums`；中文字体回退 `Microsoft YaHei`。
- 间距 **4/8px** 栅格：`--s-1..--s-8 = 4,8,12,16,20,24,32,48`。
- 圆角三档，全站唯一：面板 `--r-panel 6px`、控件 `--r-ctl 4px`、胶囊 `--r-pill 999px`。
- 层级表：`--z-nav 10 < --z-dropdown 20 < --z-drawer 30 < --z-modal 40 < --z-toast 50`，禁止裸 z-index。

## 3. 布局

- 设计基准 **1920×1080**；内容区用栅格自适应。
- **顶栏 48px**：品牌 · 页面标题 · 连接状态 · 时钟 · 主题 / 主题色。
- **左导航**：≥1280 展开（208px，图标 + 文字）；800–1279 收为图标栏（56px）；<800 汉堡抽屉。
- 内容区 padding 16px；面板间距 12px。
- 断点实测：1920 / 1280 / 980 / 800 / 480。

## 4. 组件

| 组件 | 规则 |
|---|---|
| 面板 | `surface-1` + 1px `--line`；标题条：左侧 3px 强调色条 + 标题 + 右置单位/操作 |
| KPI | 数值 28px tabular，单位小一号灰字，下方次要指标 + 迷你趋势；同屏主 KPI ≤4 |
| 状态徽章 | 胶囊，图标 + 文字，底色为语义色 12% 混合 |
| 表格 | 行高 36px，表头固定，数值列右对齐，长文本 `title` 展示全文，行 hover 高亮，键盘可聚焦 |
| 按钮 | 每页主操作 ≤1 个（实心强调色）；次要为描边；禁用态降低不透明度 + `cursor:not-allowed` + 原因 tooltip |
| 抽屉 | 右侧滑入 480–560px，Esc 关闭，点击遮罩关闭 |
| 提示 | toast 右下角，成功 3s / 失败 6s（可手动关闭，错误含下一步动作） |
| 空态 | 说明“这里会有什么” + 操作入口，禁止空白 |
| 加载 | 骨架屏形状贴合最终布局；>1s 无反馈视为缺陷 |
| 错误 | 错误码 + 人话原因 + 重试按钮 |

## 5. 动效

| 类型 | 时长 | 曲线 |
|---|---|---|
| 微反馈（hover / 按压） | 120–200ms | `--ease-out` = `cubic-bezier(.16,1,.3,1)` |
| 面板 / 抽屉 / 弹层 | 300–450ms | `--ease-out` |
| 列表入场 stagger | 40–80ms 间隔，≤3 个并发主体 | `--ease-out` |
| 进行中脉冲 / 告警呼吸 | 1.6–2s 循环 | ease-in-out（循环允许） |

- 只动 `opacity` / `transform`；动效必须有动机（层级引导、状态变化）。
- `prefers-reduced-motion: reduce` 时全部降级为直接呈现。

## 6. 数据格式

- 时间：`2026-11-02 14:49:43`（本地时间，不显示毫秒与时区）；相对时间仅用于告警流（“刚刚 / 3 分钟前”），`title` 给出绝对时间。
- 时长：`12.3 s`；≥60s 用 `1:05`；单位写在数值后并用小号灰字。
- 百分比一位小数；计数千分位；空值统一 `—`。
- 周期号 / 证据哈希使用等宽字体，哈希显示前 12 位 + 复制按钮。

## 7. 页面规范

### 7.1 总览 `#/overview`
```
┌ KPI ─────────────────────────────────────────────────────────┐
│ 今日周期   今日合规率   平均节拍(目标)   今日异常周期          │
├ 工位墙（2 列卡片）──────────────────────┬ 右栏 ───────────────┤
│ ┌ 工位名·id  [状态] ┐ ┌ …               │ 近 24 小时合规趋势  │
│ │ 实时画面 4:3       │ │                 │ （堆叠柱：合格/不合格/待复核）
│ │ 步骤条 S1 S2 …     │ │                 ├ 实时告警（流）      │
│ │ 周期计时 / 节拍进度│ │                 │                     │
│ └────────────────────┘ └                 └─────────────────────┘
```
- 卡片点击 → 实时监控；告警项点击 → 追溯抽屉。

### 7.2 实时监控 `#/live/:id`
- 左：视频（保持画面比例，右上角状态徽章与周期计时），下方 **节拍条**（总长 = 节拍时间，按步骤已用时长分段，超出部分标红）。
- 右：**步骤轨道**（纵向，状态图标 + 步骤名 + 证据说明 + 耗时，进行中高亮并显示已用时），**违规**列表，**区域状态**芯片（手在区域 / 物件状态）。

### 7.3 追溯 `#/trace`
- 筛选条：工位 · 结果（分段控件：全部/合格/不合格/待复核）· 序列号搜索 · 刷新。
- 表格列：开始时间 · 工位 · 周期号 · 序列号 · 结果 · 耗时（相对节拍） · 违规摘要。
- 行点击 → 右侧抽屉：结果头部、步骤甘特图（含节拍线）、违规、证据图（点击放大）、规则指纹与证据哈希。

### 7.4 SOP 配置 `#/config/:id`
- 左：现场画面 + SVG 区域叠加（悬停高亮、点击选中）。
- 右：标签页 **步骤规则 / 结果核验 / 规则源码**。
- 区域编辑、标定向导标注为“即将提供”，禁用并写明原因；真实工位的“采集参考图”按钮按配置启用。

## 8. 无障碍与键盘

- 所有可点击元素可聚焦，焦点环 2px 强调色。
- `Esc` 关闭抽屉 / 放大图 / 弹出菜单；`/` 聚焦搜索框（追溯页）。
- 颜色之外必有图标与文字。

## 9. 验收（每页必须过）

布局构图 · 令牌一致性 · 排版 · 交互状态完备 · 动效 · 信息设计 · 反馈即时性 · 响应式与主题 · 语义文案；逐维 ≥9/10，以浏览器实测截图为证。
